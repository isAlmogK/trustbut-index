# Measure trustbut 0.7.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The study counts trustbut 0.7.0's `change-not-proven`, judges success on factual accuracy and run coverage (precision and hit rate reported without a bar), drafts labels with prompt v2, and pins trustbut 0.7.0.

**Architecture:** `countedFindings` resolves the family of `change-not-proven` per receipt; `aggregate` refuses a results folder that mixes trustbut generations; `verdict` gets an accuracy check; the report shows the new tiles and the "Nothing proves the change" precision line.

**Tech Stack:** TypeScript (ESM, `.js` import suffixes), Node 22, Vitest, tsx.

**Spec:** `docs/superpowers/specs/2026-10-17-trustbut-0.7.0-design.md`. Read it first.

## Global Constraints

- Test first (AGENTS.md). Deterministic. `npm test`, `npm run typecheck` (check `package.json` for the exact script names).
- `change-not-proven` → `untested-change` when the receipt has no `proofs` (absent or empty), else `proof-gap`.
- Generation line: trustbut **0.7.0**. A folder with receipts both below and at/above 0.7.0 is an error naming one version from each side.
- `THRESHOLDS = { accuracy: 0.95, coverage: 0.5 }`. Accuracy = (real + benign) / (real + benign + false) over all labeled findings, Wilson 95%. `pass` = accuracy.pass && coverage.pass. Precision and hit rate are reported with `target: null` and `pass: null`.
- Not-proven precision: real / (real + benign + false) over labeled items whose `finding.id === 'change-not-proven'`.
- Commit after each task, conventional message ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage only files you changed.
